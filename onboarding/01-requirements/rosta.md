# 1. Требования — ROSTA

> 🎯 **Цель:** убедиться, что касса ROSTA подходит для подключения **Halyk Рестораны**.<br>Общие требования к заведению (расчётный счёт Halyk Bank, POS-терминал и Terminal ID, MCC, формат, интернет), сводная таблица функций и чек-лист этапа — в [«1. Требования»](README.md). Здесь — только требования ROSTA.

---

# Сводка требований ROSTA

| Параметр | Требование |
|---|---|
| Минимальная версия ПО | ROSTA **1.13.9 или выше** |
| ОС / оборудование | ОС Windows |
| Что нужно дополнительно | Доступ владельца к **ROSTA Mobile Office**, приложение Halyk для OTP-кода |
| Если версия ниже | Обновить ROSTA до актуальной версии, иначе интеграция не отображается |

---

# Требования ROSTA

- [ ] Версия ПО ROSTA на объекте — **не ниже 1.13.9**.
- [ ] Доступ **владельца** к **ROSTA Mobile Office**.
- [ ] Доступ к **приложению Halyk** для получения OTP-кода.

## Если версия ниже 1.13.9

> 🚫 Обновите ROSTA до актуальной версии. Для самостоятельного подключения нужна версия **1.13.9 или выше** — до обновления подключение невозможно.
