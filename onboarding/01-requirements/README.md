# 1. Требования

> 🎯 **Цель:** до начала любых работ убедиться, что заведение и касса подходят для подключения **Halyk Рестораны**.<br>**Для кого:** инженер, любая ERP · **Этап 1 из 8**.<br>Сначала проверьте общие требования на этой странице, затем — требования своей ERP. Если хотя бы одно обязательное требование не выполнено — онбординг не начинаем.

---

# Обязательные требования к заведению (все ERP)

- [ ] **Расчётный счёт в Halyk Bank.**
- [ ] **Активный POS-терминал Halyk** — на нём будут отображаться оплаты Halyk Рестораны; нужен его **Terminal ID**.
- [ ] **Категория деятельности «Кафе и рестораны»** — MCC **5411, 5441, 5462, 5812, 5813, 5814, 7996, 7999**.
- [ ] **Формат заведения** — кафе / ресторан с обслуживанием за столом.
- [ ] **Интернет** на кассе (требования к скорости, если есть, — в файле ERP).

> 🚫 **Не подходят** точки, где гостя обслуживают сразу на кассе (формат «заказал и оплатил у кассы»). КЦ обязательно уточняет: *кафе или точка на вынос?* Если формат обслуживания — сразу на кассе, подключение не выполняется.

> ⚠️ Если у ресторана несколько POS-терминалов — заранее определите, **каким физическим терминалом** ресторан фактически принимает оплаты. Его Terminal ID выбирается на портале.

# Требования по ERP

Версии ПО, оборудование, лицензии, плагины и доступы — в файле своей ERP:

- [iiko](iiko.md) — Windows 10+, iikoFront 8.7+, плагин «Halyk — настройка».
- [r_keeper](r_keeper.md) — Windows 10+, r_keeper 7.7.0.390+, лицензия и GUID валюты.
- [Poster](poster.md) — доступ к аккаунту Poster; для внешнего меню — тариф PRO / BUSINESS.
- [Paloma365](paloma365.md) — актуальная версия ПО, плагин «Использовать Halyk Рестораны».
- [ROSTA](rosta.md) — ROSTA 1.13.9+, доступ владельца к ROSTA Mobile Office, приложение Halyk для OTP.

# ✅ Чек-лист этапа

Общие требования:

- [ ] Расчётный счёт в Halyk Bank есть.
- [ ] Активный POS Halyk есть, Terminal ID известен (при нескольких терминалах — определён нужный физический терминал).
- [ ] MCC — один из 5411, 5441, 5462, 5812, 5813, 5814, 7996, 7999.
- [ ] Формат — обслуживание за столом (не «сразу на кассе»).
- [ ] Интернет на кассе есть.
