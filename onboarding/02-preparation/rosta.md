Требования — ROSTA».<br>**Следующий шаг:** «3. Подключение — ROSTA».

# Перед началом

- [ ] Версия ROSTA на объекте — **не ниже 1.13.9**. Проверка на кассе — кнопка **«i»**. Если ниже — обновите до актуальной.
- [ ] У владельца есть доступ к **ROSTA Mobile Office** (через него владелец сам выполняет подключение).
- [ ] Есть доступ к **приложению Halyk**, из которого берётся **OTP-код** для безопасного подключения интеграции.
- [ ] Определены **торговая точка** и **касса** для интеграции, их настройки в ROSTA проверены.

<details>
<summary>Данные для портала и выезда (КЦ / сервисант)</summary>

**КЦ вносит в Таблицу по привлечению:** название ресторана; БИН; формат (кафе или точка на вынос; если обслуживание сразу на кассе — **не подходит**); ERP и версия (ROSTA **1.13.9+**); адрес точки; контакт ответственного.

**Сервисант перед выездом:** созванивается с рестораном и подтверждает готовность; создаёт чат; получает данные по ROSTA — версия ПО **1.13.9 или выше**; доступ владельца к **ROSTA Mobile Office**; торговая точка, касса и меню; настроенный способ оплаты Halyk; доступ к приложению Halyk для OTP-кода.

**Для портала:**

- **БИН**, **адрес** точки и соответствующий **ID терминала**.
- **Terminal ID** физического POS-терминала Halyk, которым ресторан фактически принимает оплаты: [HALYK POS: Инструкция по получению Terminal ID](../../guides/common/halyk-pos-terminal-id.md)
- Карточка ресторана: ссылка 2ГИС (без пробелов и лишних символов), логотип при наличии; управляющий готов проверить карточку и выбрать функции.
- Для чаевых: у официантов есть карта Halyk Bank; телефоны сотрудников внесены в ROSTA (шаг 3).

> ℹ️ Для ROSTA обязательны все общие этапы: шаги на портале онбординга (заявка, выбор POS-терминала), [привязка столов и QR-коды](../04-tables/README.md) и [Telegram-группа сотрудников](../05-telegram/README.md).

</details>

# Шаг 1. Способ оплаты «Halyk»

1. В ROSTA создайте (или настройте существующий) способ оплаты **«Halyk»**.
2. Тип способа оплаты — **«Безналичный»**.

> ✅ Готово, если: способ оплаты «Halyk» с типом «Безналичный» есть в ROSTA.

---

# Шаг 2. Продуктовое (внешнее) меню

| Функции ресторана | Нужно ли продуктовое меню |
| --- | --- |
| Базовая QR-оплата, чаевые, вызов официанта, Telegram, бронирование | **Нет** — шаг пропустите |
| **Меню** (гость видит категории, блюда и цены в карточке ресторана в Halyk SuperApp) | **Да** |
| **Самовывоз** (гость оформляет заказ из меню, заказ поступает на кассу) | **Да** + дополнительные настройки |

**Ограничения:**

- версия ROSTA **1.13.9+**, иначе интеграция «Halyk рестораны» не отображается;
- **API-ключ для ROSTA не используется** — подключение идёт через ROSTA Mobile Office.

**Когда:** сейчас, на этапе 2, создайте и сохраните продуктовое меню в **ROSTA Back Office** по инструкции [ROSTA: создание внешнего (продуктового) меню для Halyk Рестораны](../../guides/rosta/external-menu.md). Запомните название меню: оно **выбирается на этапе 3** при подключении интеграции в ROSTA Mobile Office — [3. Подключение — ROSTA](../03-connection/rosta.md). Сохранение меню в Back Office подключение не завершает. На этапе 7 меню только проверяется.

<details>
<summary>Частые проблемы</summary>

- **Интеграция «Halyk рестораны» не отображается** — проверьте версию ROSTA (нужна 1.13.9+).
- **Нужного способа оплаты нет** — создайте или настройте способ оплаты «Halyk» в ROSTA.
- **Нет раздела или кнопки «Добавить», меню пустое** — см. раздел «Если возникла проблема» [инструкции по меню](../../guides/rosta/external-menu.md).
- **Не отображается торговая точка, касса или меню** — проверьте их настройки / сохранение в ROSTA и учётную запись/заведение; далее — поддержка ROSTA.

</details>

Официальная инструкция ROSTA: [Инструкция по самостоятельной интеграции](https://academy.rosta.kz/?article=f45ca3e3-be09-4144-903e-1794ea994002)

# Шаг 3. Телефоны сотрудников для чаевых

Внесите телефоны официантов в ROSTA: **«Справочники» → «Сотрудники»** → вкладка **«Основное»** → поле **«Телефон»** — заполните, несмотря на подсказку **«Не обязательно»**. Формат и пошаговая инструкция: [ROSTA: добавление номера телефона сотрудника для чаевых](../../guides/rosta/tips-employee-phone.md)

> ℹ️ На этапе 8 телефоны только проверяются и включаются чаевые.
