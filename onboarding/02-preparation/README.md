# Общее для всех ERP

## Данные для КЦ и портала

**КЦ вносит в Таблицу по привлечению:** название ресторана; БИН; формат (кафе или точка на вынос; если обслуживание сразу на кассе — **не подходит**); ERP и её версия; адрес точки; контакт ответственного. Данные, которые нужны только конкретной ERP (CRMID для iiko, ObjectId для r\_keeper и т. п.), — на странице ERP.

**Сервисант перед выездом:** созванивается с рестораном и подтверждает готовность; создаёт чат; получает данные по своей ERP (перечень — на странице ERP).

**Для портала:**

- **БИН**, **адрес** точки и соответствующий **ID терминала**.
- **Terminal ID** физического POS-терминала Halyk, которым ресторан фактически принимает оплаты: [HALYK POS: Инструкция по получению Terminal ID](../../guides/common/halyk-pos-terminal-id.md)
- Столы созданы в ERP; нумерация в ERP = фактическая; подготовлены физические QR-коды и схема столов (для режима «По столам»).
- Telegram-группа сотрудников и возможность добавить бота **@HalykRestaurantBot** администратором.
- Карточка ресторана: ссылка 2ГИС (без пробелов и лишних символов), логотип при наличии; управляющий готов проверить карточку и выбрать функции.

> ℹ️ Для ROSTA, как и для остальных ERP, нужны шаги на портале, привязка столов (QR-коды) и Telegram-группа сотрудников.

## Внешнее меню: нужно ли и когда

Внешнее меню нужно, **только если ресторану нужны функции «Меню» или «Самовывоз»**. Для базовой QR-оплаты, чаевых, вызова официанта, Telegram и бронирования меню не требуется.

| ERP | Что сделать на этапе 2 | Когда меню выбирается / загружается | Инструкция |
| --- | --- | --- | --- |
| iiko | Создать меню Halyk QR Menu и API-ключ Cloud API | **Этап 7** — на портале по API-ключу | [Внешнее меню v2 и API Key](../../guides/iiko/external-menu-v2-api-key.md) |
| Poster | Создать источник заказа (тариф PRO / BUSINESS) | **Этап 3** — на портале после входа в аккаунт Poster | [Внешнее меню POSTER](../../guides/poster/external-menu.md) |
| ROSTA | Создать продуктовое меню в Back Office | **Этап 3** — в ROSTA Mobile Office при подключении интеграции | [ROSTA: продуктовое меню](../../guides/rosta/external-menu.md) |
| Paloma365 | Создать меню 1 уровня и **выбрать его в плагине на кассе** | **Этап 2** — в плагине Halyk Рестораны на кассе | [Внешнее меню Paloma365](../../guides/paloma365/external-menu.md) |
| r\_keeper | ⚠️ Инструкции пока нет — обратитесь к инженеру Halyk | — | [RKEEPER: внешнее меню (заглушка)](../../guides/r_keeper/external-menu.md) |

API-ключ на портале вводится **только для iiko**; для остальных ERP на шаге API-ключа нажимают «Пропустить шаг».
