# Перед началом

### Обслуживающий дилер

Это компания, которая внедряла r\_keeper, оказывает техподдержку, продлевает лицензии и обслуживает оборудование. Где найти контакты:

- в договоре сопровождения;
- на кассе в разделе <b>«Инфо о дилере»</b>;
- запросить у технической поддержки r\_keeper.

### Лицензия по подписке

1. Дилер проверяет текущую конфигурацию r\_keeper и определяет необходимые лицензии и модули.
2. Готовит коммерческое предложение и выставляет счёт на лицензии и работы по настройке (подписка — ежемесячная или годовая).
3. Ресторан подписывает договор (если требуется), оплачивает счёт и передаёт подтверждение оплаты дилеру.
4. Дилер регистрирует лицензии в системе лицензирования r\_keeper и настраивает интеграцию.

### Данные для дилера

- [ ] <b>Код ресторана (ObjectId)</b> r\_keeper — вводится на портале; если неизвестен — уточнить у дилера.
- [ ] Номер лицензии r\_keeper.
- [ ] Название организации и ресторана, <b>БИН</b>, адрес точки.
- [ ] Количество кассовых станций.
- [ ] Версия Windows и версия кассового сервера r\_keeper (требуется <b>r\_keeper 7.7.0.390+</b>).
- [ ] Обслуживающий дилер и его контакты.
- [ ] ФИО и мобильный номер представителя заведения.
- [ ] Terminal ID активного POS-терминала Halyk.

<b>Сервисант перед выездом:</b> созванивается с рестораном и подтверждает готовность; создаёт чат; получает данные по r\_keeper — контакты техподдержки, ObjectId, количество и нумерацию столов, подтверждение выдачи лицензии и получения GUID валюты.

<b>Для портала:</b>

- Telegram-группа сотрудников и возможность добавить бота <b>@HalykRestaurantBot</b> администратором.
- Карточка ресторана: ссылка 2ГИС (без пробелов и лишних символов), логотип при наличии; управляющий готов проверить карточку и выбрать функции.
- Для чаевых: у официантов есть карта Halyk Bank; телефоны сотрудников внесены в r\_keeper (шаг 3).

# Шаг 1. Тип оплаты (валюта Halyk QR)

1. Дилер создаёт в r\_keeper валюту <b>Halyk QR</b> — после интеграции заказ закрывается как <b>HALYK QR</b>.
2. Получите <b>GUID валюты</b> до начала подключения.

> ❔ Куда и кому передаётся GUID валюты и какие именно настройки валюты делает дилер, в источниках не описано. Уточнить у инженера Halyk.

<details>
<summary>Если потом оплата пройдёт, а чек не закроется</summary>

Причина — настройки валюты в r\_keeper. Привлеките обслуживающего дилера; после исправления повторите тестовую оплату.

</details>

# Шаг 2. Внешнее меню (если нужно)

| Функции ресторана | Нужно ли внешнее меню |
| --- | --- |
| Базовая QR-оплата, чаевые, вызов официанта, Telegram, бронирование | <b>Нет</b> — шаг пропустите |
| <b>Меню</b> | <b>Да</b> |
| <b>Самовывоз</b> | <b>Да</b> + дополнительные настройки |

> ⚠️ <b>API-ключ для r\_keeper не используется</b> — на портале шаг API key пропускается («Пропустить шаг»), в том числе при подключении меню и самовывоза. Порядок настройки меню и API для iiko к r\_keeper не применяется.

<b>Когда и как:</b> процедура создания и выбора меню для r\_keeper не описана — см. заглушку [RKEEPER: внешнее меню для Halyk Рестораны](../../guides/r_keeper/external-menu.md).

> ⚠️ Инструкции по меню для r_keeper пока нет — обратитесь к инженеру Halyk.

# Шаг 3. Телефоны сотрудников для чаевых

Внесите телефоны официантов в менеджерской станции: <b>«Персонал» → «Работники»</b> → расширенные свойства → поле <b>«Телефон»</b> (системное имя <b>PhoneNumber</b>). Если поля нет — добавьте его по шагам 4–10 инструкции. Формат и пошаговая инструкция: [RKEEPER: добавление номера телефона сотрудника для чаевых](../../guides/r_keeper/tips-employee-phone.md)

> ℹ️ На этапе 8 телефоны только проверяются и включаются чаевые.
