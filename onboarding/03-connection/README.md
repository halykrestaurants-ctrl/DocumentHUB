# 3. Подключение

> 🎯 **Цель:** создать заявку на портале онбординга, связать ERP ресторана с **Halyk Рестораны** и выбрать POS-терминал Halyk.<br>**Для кого:** инженер, любая ERP · **Этап 3 из 8**.<br>Начинайте только после выполнения этапа [«2. Подготовка к подключению»](../02-preparation/README.md). На этой странице — общие шаги; подключение конкретной ERP — в её файле.

# 1. Создание заявки

Откройте [портал онбординга Halyk Рестораны](https://lifestyle.halykbank.kz/service-man/) и авторизуйтесь.

1. Введите **БИН организации**.
2. Нажмите **«Отправить»**.
3. Выберите **«Создать новую заявку»**.
4. Выберите **адрес заведения**.
5. Выберите **ID терминала**, соответствующий этому адресу.

> ⚠️ Перед продолжением проверьте **БИН, адрес и ID терминала**: заявка должна относиться именно к той точке, которую вы подключаете.

**Ожидаемый результат:** создана заявка для нужного ресторана, открыт выбор ERP-системы. Дальше — шаги подключения из файла своей ERP.

> ⚠️ TODO: для ROSTA из источников неясно, нужно ли проходить шаги на портале онбординга (создание заявки, выбор POS-терминала, привязка столов). Уточнить у инженера Halyk.

# 2. Подключение ERP

Выполните шаги из файла своей ERP (см. таблицу выше). После завершения сбора данных и нажатия **«Далее»** портал переходит к выбору POS-терминала.

> ⏳ Во время сбора данных не закрывайте страницу, не обновляйте браузер и не запускайте процесс повторно.

---

# 3. Выбор POS-терминала Halyk

Портал покажет список POS-терминалов Halyk с их **Terminal ID** — выберите тот, на котором будут отображаться оплаты Halyk Рестораны.

1. Определите **Terminal ID** физического терминала, которым ресторан фактически принимает оплаты. Как узнать: [HALYK POS: Инструкция по получению Terminal ID](../../guides/common/halyk-pos-terminal-id.md).
2. Найдите его в списке на портале и выберите.
3. Нажмите **«Далее»**.

> ⚠️ Если в ресторане **несколько терминалов** — обязательно сверяйте Terminal ID с конкретным физическим устройством нужной точки.

# Если что-то не работает

Проблемы, специфичные для ERP (код, вход, плагин), — в файле своей ERP.

<details>
<summary>Сбор данных не завершается</summary>

Не обновляйте страницу и не запускайте процесс повторно. Проверьте интернет на кассе и корректность данных подключения вашей ERP (код / код ресторана / аккаунт). Если продолжить не получается — обратитесь к инженеру Halyk Bank.

</details>

<details>
<summary>Неизвестен Terminal ID / нужного POS нет в списке</summary>

Определите Terminal ID на физическом терминале по [инструкции](../../guides/common/halyk-pos-terminal-id.md) и сверьте адрес выбранной точки. Если не помогло — проверьте **MCC-код** и **модель терминала**, затем обратитесь к инженеру Halyk Bank.

</details>

<details>
<summary>POS-терминал Halyk не показывает транзакции Lifestyle</summary>

1. Перейдите в **«История»**.
2. Нажмите **«Обновить историю»**.
3. Дождитесь загрузки транзакций.

</details>
