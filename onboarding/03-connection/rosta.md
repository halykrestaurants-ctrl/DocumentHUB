# Подключение в ROSTA Mobile Office

Для ROSTA подключение выполняется **со стороны ROSTA** — владельцем через **ROSTA Mobile Office** (версия ROSTA **1.13.9+**).

Пошаговая инструкция со скриншотами, проверкой перед подключением и ответами на вопросы: **[ROSTA: подключение «Halyk рестораны»](../../guides/rosta/connection.md)**.

Кратко: профиль → «Все доступные интеграции» → «Halyk рестораны» → «Подключить» → торговая точка → касса → меню → способ оплаты **Halyk** → OTP-код из приложения Halyk → «Подключить».
