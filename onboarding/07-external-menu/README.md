# 7. Внешнее меню

> 🎯 **Цель:** на портале пройти шаг API-ключа / меню и проверить, что меню ресторана отображается в Halyk Рестораны.<br>**Для кого:** инженер, подключающий ресторан · **Этап 7 из 8** (опциональный).<br>Выполняйте, **только если ресторану нужны функции «Меню» или «Самовывоз»**. Если не нужны — на шаге API-ключа на портале нажмите **«Пропустить шаг»** и переходите к этапу 8.

# Общее для всех ERP

## Когда меню выбирается

Меню создаётся заранее в ERP (этап 2). На этом этапе меню загружается на портале **только для iiko**; для остальных ERP оно уже выбрано раньше, и здесь только проверяется.

| ERP | Когда и где выбирается / загружается меню | Инструкция по меню |
| --- | --- | --- |
| iiko | **Этап 7** — на портале по API-ключу: [7. Внешнее меню — iiko](iiko.md) | [Внешнее меню v2 и API Key](../../guides/iiko/external-menu-v2-api-key.md) |
| Poster | **Этап 3** — на портале после входа в аккаунт Poster | [Внешнее меню POSTER](../../guides/poster/external-menu.md) |
| ROSTA | **Этап 3** — в ROSTA Mobile Office при подключении интеграции | [ROSTA: продуктовое меню](../../guides/rosta/external-menu.md) |
| Paloma365 | **Этап 2** — в плагине Halyk Рестораны на кассе | [Внешнее меню Paloma365](../../guides/paloma365/external-menu.md) |
| r\_keeper | ⚠️ Инструкции пока нет — обратитесь к инженеру Halyk | [RKEEPER: внешнее меню (заглушка)](../../guides/r_keeper/external-menu.md) |

## Шаг API-ключа на портале

- **iiko** — введите API-ключ Cloud API, созданный на этапе 2.
- **r\_keeper, Poster, Paloma365, ROSTA** — нажмите **«Пропустить шаг»**: API-ключ не вводится, в том числе при подключении меню и самовывоза.

## Проверка меню

- **Категории**, **товары** и **цены** совпадают с меню в ERP.
- Меню принадлежит **нужному ресторану**.
- Меню отображается в карточке ресторана в **Halyk SuperApp**.
