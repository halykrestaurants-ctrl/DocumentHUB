# 2. Подготовка к подключению — ROSTA

> 🎯 **Цель:** подготовить всё внутри ROSTA до подключения: способ оплаты «Halyk» и, при необходимости, продуктовое (внешнее) меню.<br>**Для кого:** инженер, подключающий ресторан на ROSTA · Этап 2 из 8.<br>Начинайте только после этапа «1. Требования — ROSTA».<br>**Следующий шаг:** «3. Подключение — ROSTA».

---

# Перед началом

- [ ] Версия ROSTA на объекте — **не ниже 1.13.9**. Проверка на кассе — кнопка **«i»**. Если ниже — обновите до актуальной.
- [ ] У владельца есть доступ к **ROSTA Mobile Office** (через него владелец сам выполняет подключение).
- [ ] Есть доступ к **приложению Halyk**, из которого берётся **OTP-код** для безопасного подключения интеграции.
- [ ] Определены **торговая точка** и **касса** для интеграции, их настройки в ROSTA проверены.

---

# Шаг 1. Способ оплаты «Halyk»

1. В ROSTA создайте (или настройте существующий) способ оплаты **«Halyk»**.
2. Тип способа оплаты — **«Безналичный»**.

> ✅ Готово, если: способ оплаты «Halyk» с типом «Безналичный» есть в ROSTA.

---

# Шаг 2. Продуктовое (внешнее) меню

| Функции ресторана | Нужно ли продуктовое меню |
| --- | --- |
| Базовая QR-оплата, чаевые, вызов официанта, Telegram, бронирование | **Нет** — шаг пропустите |
| **Меню** (гость видит категории, блюда и цены в карточке ресторана в Halyk SuperApp) | **Да** |
| **Самовывоз** (гость оформляет заказ из меню, заказ поступает на кассу) | **Да**  • дополнительные настройки |

Подробная инструкция со скриншотами: [ROSTA: создание внешнего (продуктового) меню для Halyk Рестораны](rosta-создание-внешнего-продуктового-меню-для-halyk-рестораны.md)

1. Войдите в **ROSTA Back Office**.
2. Откройте **«Справочники»** → блок **«Другое»** → **«Продуктовые меню»**.
3. Нажмите **«Добавить»**.
4. Заполните **«Наименование»** (например, **Halyk menu** — фиксированное название не требуется, запомните своё).
5. Перенесите нужные группы и товары из левой панели **«Номенклатура»** в правую панель **«Меню»**.
6. Нажмите **«Сохранить и закрыть»**.
7. Откройте меню повторно и проверьте, что состав сохранился.

> ⚠️ Товар только в левой панели **не добавлен** в меню. Сохранение меню в Back Office **не завершает** подключение — созданное меню нужно будет выбрать при подключении интеграции в ROSTA Mobile Office (этап «3. Подключение — ROSTA»).

> ℹ️ **API-ключ для ROSTA не используется** — подключение идёт через ROSTA Mobile Office.

<details>
<summary>Частые проблемы</summary>

- **Интеграция «Halyk рестораны» не отображается** — проверьте версию ROSTA (нужна 1.13.9+).
- **Нужного способа оплаты нет** — создайте или настройте способ оплаты «Halyk» в ROSTA.
- **Нет раздела или кнопки «Добавить»** — администратор ROSTA проверяет доступ к продуктовым меню.
- **Меню пустое** — проверьте правую панель, добавьте позиции, сохраните.
- **Не отображается торговая точка, касса или меню** — проверьте их настройки / сохранение в ROSTA и учётную запись/заведение; далее — поддержка ROSTA.

</details>

Официальная инструкция ROSTA: [Инструкция по самостоятельной интеграции](https://academy.rosta.kz/?article=f45ca3e3-be09-4144-903e-1794ea994002)

- [ ] У владельца есть доступ к ROSTA Mobile Office.
- [ ] Есть доступ к приложению Halyk для OTP-кода.

- [ ] Если нужны «Меню» или «Самовывоз»: продуктовое меню создано и сохранено в ROSTA Back Office, состав проверен.
